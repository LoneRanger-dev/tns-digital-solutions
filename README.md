## ⚡ How to Run Locally

You can test this project immediately in two ways:

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to open it in any web browser.

### Option 2: Local HTTP Server
Run with Node.js:
```bash
npx serve .
```
Then open `http://localhost:3000` in your browser.

## 🌐 How to Push to GitHub & Deploy

### Step 1: Initialize Git and Commit
In your terminal (inside the root folder):
```bash
git init
git add .
git commit -m "feat: launch TnS Digital Solutions flagship platform"
```

### Step 2: Push to Your GitHub Repository
Create a new repository on GitHub (e.g., `tns-digital-solutions`), then run:
```bash
git remote add origin https://github.com/YOUR_USERNAME/tns-digital-solutions.git
git branch -M main
git push -u origin main
```

*(Note: The `.gitignore` file automatically excludes large legacy WordPress zip archives to keep your repo fast and well within GitHub's 100MB file limit).*

### Step 3: Deploy in 60 Seconds

#### Deploy to Vercel:
1. Log in to [vercel.com](https://vercel.com) and click **"Add New Project"**.
2. Select your `tns-digital-solutions` GitHub repository.
3. Keep default settings (the included `vercel.json` configures everything automatically).
4. Click **Deploy**!

#### Deploy to Netlify:
1. Log in to [netlify.com](https://netlify.com) and click **"Add new site" -> "Import an existing project"**.
2. Select GitHub and choose your repository.
3. The included `netlify.toml` automatically configures publish directory (`.`).
4. Click **Deploy Site**!

#### Deploy to Render:
1. Log in to [render.com](https://render.com) and create a **"Static Site"**.
2. Connect your GitHub repository.
3. Set Publish directory to `./`.
4. Click **Create Static Site**!
